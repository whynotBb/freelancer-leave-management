## 3. 역할별 E2E 시나리오 테스트 계획

### 🎭 시나리오 1: 계정 회원가입 & 승인 워크플로 (SUPER_ADMIN)
1. **프리랜서 회원가입**
   - 신규 사용자가 이메일/비밀번호/이름으로 가입 신청 (`PENDING` 상태)
   - 가입 대기 상태에서 로그인 시도 시 "승인 대기 중인 계정입니다" 에러 메세지 확인
2. **관리자 가입 승인**
   - 최고관리자(`SUPER_ADMIN`) 계정 로그인 -> `/admin/users` 진입
   - 가입 신청 탭에서 신청자 정보(입사일, 기본 결재자 지정) 확인 후 `승인` 클릭
   - 실시간 SSE 알림으로 관리자 뱃지 카운트 갱신 확인
3. **로그인 및 권한 확인**
   - 승인된 프리랜서 계정으로 로그인 성공 및 대시보드 리다이렉트 확인

---

### 🎭 시나리오 2: 휴가계 신청 & 결재 워크플로 (FREELANCER & APPROVER)
1. **휴가 신청서 작성**
   - 프리랜서 로그인 -> `/documents` (내 문서) 이동 -> [휴가 신청] Sheet 열기
   - 결재자 지정 (기본 결재자 자동 세팅 확인)
   - 시작일~종료일 선택 (주말 및 공휴일 제외 신청일수 자동 계산 확인)
   - 연차/오전반차/오후반차 선택 후 사유 입력 및 제출
2. **잔여연차 초과 경고 (엣지 케이스)**
   - 잔여연차보다 큰 일수의 휴가 신청 시 확인 다이얼로그(마이너스 경고) 팝업 및 제출 승인 확인
3. **결재함 확인 및 결재 처리**
   - 결재자(`APPROVER` 또는 `SUPER_ADMIN`) 로그인 -> `/approvals` 진입
   - 대기 탭에서 신청 문서 확인 -> 상세 모달 오픈
   - [승인] 또는 [반려 (반려 사유 입력)] 처리
4. **결과 반영 확인**
   - 프리랜서 로그인 -> 대시보드 및 내 문서 타임라인에서 상태(`승인`/`반려`) 및 잔여 연차 차감 결과 확인
   - SSE 알림 팝오버에 "휴가가 승인되었습니다" 메시지 도착 확인

---

### 🎭 시나리오 3: 관리자 기능 & 엑셀 다운로드 (SUPER_ADMIN)
1. **연차 수동 조정 및 이력 기록**
   - 관리자 `/admin/users` -> 프리랜서 상세 패널 열기 -> [연차 수동 조정]
   - 조정 수량 (+2일 또는 -1일) 및 사유 입력 -> 저장
   - 내 문서 타임라인 및 관리자 변경 이력 탭에 조정 로그 정상 기재 확인
2. **비밀번호 초기화**
   - 임의 사용자 비밀번호 초기화 실행 -> 임시 비밀번호 생성 -> 해당 임시 비밀번호로 로그인 및 변경 강제 확인
3. **공휴일 관리**
   - `/admin/holidays` 이동 -> 신규 공휴일(예: 추석/설날) 추가 -> 휴가 신청 시 신청일수 자동 차감 검증
4. **엑셀 추출 검증**
   - `/admin/users` -> [엑셀 다운로드] 버튼 클릭
   - 다운로드된 `.xlsx` 파일 내 3개 시트 확인:
     - `연차 현황 요약`
     - `2026년 월별 사용 현황` (1월~12월 매트릭스 및 하단 합계)
     - `상세 변경 이력`

---

### 🎭 시나리오 4: 모바일 & 반응형 UX 검증 (Viewport 375px~430px)
1. **모바일 대시보드 캘린더**
   - 날짜 셀 높이 및 공휴일 표시 위치(날짜 아래) 확인
   - 헤더 (년-월 / 오늘 버튼) 가로 좁을 때 반응형 줄바꿈 확인
2. **동일 날짜 다수 휴가 모달 & [more >] 팝오버**
   - 동일 일자에 3명 이상 휴가 등록 시 최대 표시 인원 후 `[more >]` 버튼 렌더링 확인
   - `[more >]` 클릭 시 미니 팝오버에 남은 인원 정상 표출
3. **휴가 상세 모달**
   - 긴 제목 작성 시 모달 밖으로 넘치지 않고 자연스럽게 줄바꿈(break-words) 확인
   - 태그(오전반차)와 타이틀 vertical align (items-center) 정렬 확인
