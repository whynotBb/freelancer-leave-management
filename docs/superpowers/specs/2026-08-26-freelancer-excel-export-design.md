# 프리랜서 정보 엑셀 다운로드

> bounded 경로로 진행한 기능입니다. 정식 브레인스토밍 spec 프로세스(질문/승인 루프 전체)를
> 거치지 않았고, 이 문서는 나중에 참고할 수 있도록 결정 배경만 짧게 남긴 기록입니다.
> 별도 구현 계획 문서는 없습니다.

## 요구사항

- 프리랜서 정보 관리 리스트 화면에서 엑셀 다운로드 (전체 / 담당만 / 체크박스로 선택)
- 프리랜서 상세 이력 패널에서 해당 1인의 엑셀 다운로드
- 엑셀에는 테이블 요약 정보 + 연차 상세 이력(발생/사용/조정/결재자 변경 등)까지 포함

## 결정 사항

**서버 사이드 생성**: 리스트 다운로드에도 각 프리랜서의 연차 상세 이력을 포함해야 해서,
클라이언트가 이미 들고 있는 데이터만으로는 부족했다(이력은 상세 패널을 열 때만 개별
fetch됨). N명분을 클라이언트에서 각각 fetch하는 대신, 서버에서 한 번에 조회해 `exceljs`로
`.xlsx`를 생성해 스트림 응답하는 방식을 선택했다.

**API**: `GET /api/admin/users/export?mode=all|mine|selected&ids=1,2,3` 하나로 리스트
다운로드(전체/담당)와 선택 다운로드, 상세 패널의 단건 다운로드(`mode=selected&ids=<id>`)를
모두 처리한다. `requireApproverOrAbove()` 재사용. `mode=all`은 SUPER_ADMIN/APPROVER 모두
허용(화면에 이미 전체 목록이 노출되므로).

**다운로드 트리거 UX**: 별도 범위 선택 팝오버를 만들지 않고, 이미 화면에 있던
"담당 프리랜서만 보기" 토글(`onlyMine`)과 검색 필터를 그대로 활용한다. 체크된 행이 있으면
그 행들만, 없으면 `onlyMine` 토글 상태에 따라 all/mine으로 다운로드한다(검색어 필터는
다운로드 범위에 영향 없음 — 검색은 화면 탐색용).

**엑셀 구성**: `요약`(1인 1행, 테이블과 동일 컬럼) + `이력`(전체 대상자의 이력을 이름/이메일
컬럼으로 구분한 평평한 단일 시트) 2개 시트. 인원이 많아질 때 시트가 폭증하는 것을 막기 위해
프리랜서별 시트 분리는 하지 않았다.

**반응형 범위**: 체크박스 다중 선택 + 다운로드 버튼은 데스크톱 테이블(`xl:` 1280px 이상)에만
노출한다. 태블릿/모바일 카드 뷰에서는 숨긴다 — 다건 다운로드는 넓은 화면에서의 관리 작업으로
보고, 카드 뷰의 단순함을 유지했다. 상세 패널의 단건 다운로드 버튼은 뷰포트와 무관하게 항상
노출한다.

**빈 결과 처리**: 담당 프리랜서가 0명인 상태로 다운로드해도 별도 안내 없이 헤더만 있는 빈
시트를 그대로 내려준다(토스트 등 별도 UI를 새로 만들지 않기 위한 단순화 — 이 프로젝트에는
아직 토스트 인프라가 없음).

## 재사용/리팩터링

`app/api/admin/users/route.ts`의 승인된 프리랜서 조회 로직(select + 연차 잔액 계산)을
`lib/db/freelancers.ts`의 `getApprovedFreelancers()`로 추출해, 기존 리스트 API와 신규 export
API가 동일 로직을 공유하도록 했다. 동작은 기존과 동일(순수 리팩터링).
